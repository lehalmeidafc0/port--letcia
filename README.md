## 📌 Sobre o projeto

Este é o meu portfólio pessoal, criado para apresentar minha trajetória no início da carreira em tecnologia. Sou estudante de **Análise e Desenvolvimento de Sistemas na FIAP** e estou em busca do meu primeiro estágio na área.

O site foi inspirado em portfólios editoriais modernos, com títulos grandes, mistura de fontes, um fundo com linhas de mapa topográfico e o verde-limão como cor de destaque.

## 🧭 O que tem no site

| Seção | Conteúdo |
|---|---|
| **Início** | Ícone de código com texto sendo digitado, tecnologias girando em volta e um cartão `leticia.js` |
| **Sobre mim** | Quem sou, minha formação e o que estou estudando agora |
| **Em sala / No código** | Linha do tempo da formação (FIAP, Senac, Minas Programam) e as tecnologias que uso |
| **Cursos e certificados** | Licenças da FIAP e Alura e cursos extracurriculares (Kick, Senai, Sebrae, CNA) |
| **Projetos em destaque** | LocalLead, Soulie, Word Connect e Lista de Convidados, com links para o código e para a versão online |
| **Contato** | E-mail com botão de copiar, LinkedIn e GitHub |

## 🛠️ Tecnologias

<img src="https://skillicons.dev/icons?i=html,css,js,github" />

- **HTML5** semântico
- **CSS3** com variáveis, Flexbox, Grid, `clip-path` e animações
- **JavaScript** puro: efeito de digitação, menu, botão de copiar e o fundo topográfico desenhado em `<canvas>`
- **Google Fonts**: Bricolage Grotesque, Instrument Serif, JetBrains Mono e Mrs Saint Delafield
- **GitHub Pages** para hospedagem

## ✨ Destaques

- Layout **responsivo**, pensado para celular e computador
- Fundo com **linhas topográficas geradas por código** a cada carregamento
- Animações que respeitam a preferência de **movimento reduzido** do sistema
- Tudo em **um único arquivo** (`index.html`), sem bibliotecas externas

## 🚀 Como rodar localmente

```bash
git clone https://github.com/lehalmeidafc0/port--letcia.git
cd port--letcia
# abra o arquivo index.html no navegador
```
